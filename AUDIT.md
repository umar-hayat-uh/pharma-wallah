## Why content can be missing from the raw HTML

Every route sits under the root `src/app/loading.tsx`. A page whose server component awaits
anything (the course unit page awaited `getUnitMarkdown`; the Battle Royale pages await
Supabase) is streamed: the first HTML holds the loading UI in `<main>`, and the page arrives
later in the same response inside `<div hidden id="S:…">`, moved into place by JavaScript. A
crawler that does not run JavaScript sees an empty `<main>`. That is the "content added by JS"
flag above (26 pages, including all 22 course units).
